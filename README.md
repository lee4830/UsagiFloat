# 우사기 둥둥 · UsagiFloat

다른 앱 위에 우사기를 띄우는 Android 앱입니다. 손가락으로 옮기거나 산책 모드로 화면을 돌아다니게 할 수 있습니다.

[서명된 APK 다운로드](https://github.com/lee4830/UsagiFloat/releases/latest)

## 1.0.10

- 귀·꼬리·소품을 제외한 **둥근 몸통의 폭**을 기준으로12종 크기를 맞췄습니다. 긴 귀/퍼지는 귀는 몸통을 줄이지 않고 여유 캔버스에 표시합니다. 원본 구도와 자연스러운 늘어남/찌그러짐은 유지합니다.
- 수동 모드의 크기 슬라이더는 몸통 기준이며, 귀까지 포함한 전체 영역은 화면 안에 맞춰집니다.
- 화면이 꺼지면 GIF·랜덤·산책·절약 주기뿐 아니라1초 상태 확인과 종료 타이머 예약도 멈춥니다. 화면을 켜면 복구하며, 꺼진 동안 종료 시간이 지났다면 재표시 없이 종료합니다.
- 반복 작업을 중지하는 것으로, OS의 프로세스/알림 유지 비용까지 포함한 절대적인 배터리0을 보장하는 것은 아닙니다.

## 1.0.9

- 수동 캐릭터 **12종**: 새 GIF 7종의 배경을 분리하고 원본 프레임 수와 시간을 유지했습니다.
- 기존 5종까지 투명 여백을 정리하고 공통 캔버스로 맞췄습니다. 원본 구도·귀 길이·동작에 따른 비율 차이는 유지됩니다.
- 작은 이미지는 Lanczos 보간으로 확대했습니다. 원본에 없던 디테일을 생성하는 AI 복원은 아닙니다.
- **랜덤 재생 상세 설정**에서 전체 12개 또는 원하는 이미지만 선택하고 **선택 적용**으로 저장합니다. 최소 1개가 필요하며 1개만 고르면 그 이미지가 계속 움직입니다. 취소하면 변경하지 않습니다.
- 상세 화면은 수동 모드에서 랜덤 전환을 켰을 때 표시됩니다. 전체 모드로 전환해도 이전 사용자 선택은 기억합니다.

## 기존 기능

- 자동 종료: 기본은 **계속 실행**, 분·시간·일 단위로 최대365일까지 설정합니다.
- 남은 시간 표시: 우사기 아래 작은 반투명 표시를 켜거나 끌 수 있습니다. 기본은 켜짐이며, 타이머를 사용하지 않으면 표시하지 않습니다.
- 절약 모드: 필요할 때 켜는 옵션입니다.30초 재생/30초 정지를 반복하고, 캐릭터를 만지면 즉시 재생합니다.
- GIF의 불필요한 화면 밀도 확대를 방지하고 표시 크기에 맞춰 처리합니다. 산책에서 수동 모드로 돌아오면 사용하지 않는 산책 이미지 참조를 해제합니다.

수동 캐릭터12종, 랜덤 전환과 간격 설정, 원본 영상 프레임을 사용하는 산책 모드, 크기 조절을 지원합니다. 캐릭터를 약0.5초 누르고 아래 집으로 옮기면 종료합니다.

## 설치와 사용

Android9(API28) 이상에서 Release의 `usagi-float-1.0.10.apk`를 설치합니다. 기존 버전과 같은 서명키를 사용하므로 기존 앱 위에 업데이트할 수 있습니다.

1. 앱을 열어 시작/종료 아래의 **실행 · 표시 권한 확인**으로 다른 앱 위에 표시 권한을 허용합니다.
2. 수동/산책 모드와 원하는 설정을 고릅니다.
3. 자동 종료를 사용하려면 **시간 지정**에서 값과 단위를 고르고 **시간 적용**을 누릅니다.
4. **시작 · 우사기 띄우기**를 누르면 설정 화면이 닫히고 캐릭터가 표시됩니다.

타이머는 시작 또는 명시적인 시간 적용 시점부터 셉니다. 캐릭터 변경이나 남은 시간 표시 옵션만 바꿔도 카운트다운이 초기화되지는 않습니다. 화면이 꺼진 시간도 포함하지만, 기기를 깨우지 않으므로 화면이 꺼진 동안 만료되면 화면을 켤 때 재표시 없이 종료합니다. 시간 표시는1분을 넘으면 남은 분을 올려 표시하고 마지막1분은 초 단위로 표시합니다.

자세한 안내는 [README.txt](README.txt), 검증 범위는 [verification.txt](verification.txt)를 참고하세요.

## 빌드

Android Studio 또는 JDK17이상과 Android SDK36.1을 사용합니다. 포함된 Gradle Wrapper는9.4.1, Android Gradle Plugin은9.2.1입니다.

```sh
./gradlew testDebugUnitTest assembleDebug
./gradlew lintRelease
```

SDK 경로는 로컬 `local.properties`의 `sdk.dir` 또는 `ANDROID_HOME`으로 지정합니다. 서명 릴리스는 프로젝트 루트에 개인 `signing.properties`와 해당 키를 준비한 뒤 `./gradlew assembleRelease`로 빌드합니다. 설정 필드는 `storeFile`, `storePassword`, `keyAlias`, `keyPassword`입니다. 서명 설정이 없으면 release APK는 서명되지 않습니다.

**개인 서명키, 비밀번호, 서명 백업 ZIP은 저장소와 Release에 포함하지 않습니다.** 저장소를 복제한 사람이 자체 키로 빌드한 APK는 이 Release의 APK 위에 업데이트할 수 없습니다.

`tests/`의 ADB 테스트는 전용 에뮬레이터용입니다. 실제 휴대폰을 대상으로 실행하지 마세요.

## 검증과 한계

63개 단위 테스트와 Android11 전용 에뮬레이터에서 타이머, 표시 옵션, 절약 정지·재개, 드래그, 잠금 해제 복귀를 점검했습니다. 휴대폰의 실제 전력이나 온도를 측정하지 않았으므로 발열 원인이나 배터리 절감률을 확정하지 않습니다. 앱에는 화면을 강제로 켜 두는 플래그나 기기를 깨우는 잠금이 없습니다.

## 아트워크

비공식 개인용 앱입니다. 캐릭터와 원본 이미지의 권리는 원 권리자에게 있습니다. 사용한 GIF, 공식 사이트 아이콘, 참고 영상과 처리 방법은 [ART-SOURCES.txt](ART-SOURCES.txt)에 기록했습니다. 현재 산책 모션은 제공된 참고 영상의 캐릭터 프레임을 분리한 것으로, 영상 배경과 음성은 포함하지 않습니다.
