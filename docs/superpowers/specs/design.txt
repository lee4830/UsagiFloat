우사기 오버레이 앱 제작 설계

목적: 첨부한 투명 GIF를 다른 앱 위에서 반복 재생하는 개인 설치용 안드로이드 앱과 서명 APK 제공.

구현 방식: 안드로이드 네이티브 앱. 웹 앱은 시스템 오버레이를 직접 제공하지 못하고, 크로스플랫폼 프레임워크도 네이티브 서비스가 추가로 필요하므로 네이티브 구현을 제안한다.

확인된 사용자 흐름:
1. 앱을 열고 실행 버튼으로 다른 앱 위에 표시 권한을 확인/설정한다.
2. 시작 버튼을 누르면 앱의 설정 화면을 닫고 캐릭터 애니메이션을 표시한다.
3. 캐릭터를 드래그하면 손을 놓은 위치에 머문다.
4. 길게 누르면 화면 아래 가운데 휴지통이 나타나며, 그곳으로 옮겨 놓으면 캐릭터와 실행 서비스를 종료한다.
5. 다시 앱을 열어 시작할 수 있다.

구현 담당자 제안 세부 사항:
- 앱 이름: 우사기 둥둥. 한국어 인터페이스.
- 기본 표시 영역 약 120dp, 설정 화면에서 크기 조절 가능.
- 마지막 위치/크기를 저장하고 화면 회전 후 화면 안으로 보정한다.
- 원본 GIF 13프레임/각 100ms를 투명 배경 그대로 반복 재생한다.
- 길게 누르기는 약 500ms. 휴지통 밖에 놓으면 재생을 유지한다.
- 실행 알림에 종료 기능을 둔다. 설정 화면 종료와 표시 서비스 종료를 구분한다.
- 시작 시 화면을 닫아도 서비스는 계속 실행된다. 휴지통 종료는 서비스 종료를 의미한다.
- 우사기 얼굴 이미지 후보를 찾아 앱 아이콘으로 적용하고 출처를 기록한다.
- Android 9 이상을 기본 지원 범위로 제안한다.
- 자동 부팅 실행, 인터넷 통신, 광고, 분석 기능은 추가하지 않는다.
- 새 전용 서명키로 APK에 서명하고 서명키 및 재빌드 소스도 함께 제공한다.

검증 및 납품:
- 에뮬레이터에서 권한, 시작, 투명 애니메이션, 이동, 길게 누르기, 휴지통 종료, 재시작을 확인한다.
- APK 서명 검증 후 APK, 소스 ZIP, 서명키 보관 자료, 간단한 설치 안내를 outputs에 제공한다.
- 실제 휴대폰 제조사별 절전 및 표시 제한은 에뮬레이터 검증 범위와 구분해 안내한다.
