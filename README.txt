사용법
1. usagi-float-1.0.8.apk를 휴대폰으로 옮겨 설치합니다. 설치에 사용하는 파일 앱/브라우저의 '알 수 없는 앱 설치' 허용이 필요할 수 있습니다.
2. 우사기 둥둥을 열고 '실행 · 표시 권한 확인'을 누릅니다.
3. 시스템 설정에서 우사기 둥둥의 '다른 앱 위에 표시'를 허용하고 앱으로 돌아옵니다. 기기에 따라 앱 목록에서 우사기 둥둥을 한 번 더 선택합니다.
4. 캐릭터 선택 목록에서 원하는 캐릭터를 고르고 미리보기를 확인합니다. 크기를 조절하고 '시작 · 우사기 띄우기'를 누릅니다. 설정 화면이 닫히고 캐릭터만 계속 재생됩니다.
5. 캐릭터를 끌어서 이동합니다. 놓은 위치와 크기는 저장됩니다.
6. 약 0.5초간 가만히 누르면 하단 중앙 집이 나타납니다. 캐릭터 가운데를 집으로 옮겨 놓으면 종료됩니다. 집 밖에 놓으면 계속 재생합니다.
7. 앱의 '재생 종료' 또는 실행 알림의 '종료'로도 끝낼 수 있습니다. 다시 앱을 열고 시작하면 재생됩니다.

표시 및 실행
- 총 5개: 꼬리 흔들기 / 말랑 우사기 / 응원 우사기 / 팔짱 우사기 / 파란 후드 우사기.
- 이미 배경이 투명한 3개 GIF는 원본 그대로 사용합니다.
- 배경이 있던 2개는 프레임별 마스크 처리 후 투명 애니메이션 WebP로 저장했습니다. 프레임 수와 각 프레임의 재생 시간을 보존했습니다.
- 선택하면 미리보기가 바뀌며, 이미 떠 있는 캐릭터도 바뀝니다. 선택은 다음 실행에도 저장됩니다.
- 원본 화면 가장자리에서 잘린 귀/몸은 새로 그려 넣지 않았습니다. 원본 캐릭터 내부에 포함된 작은 글자/효과는 유지합니다.
- 크기 범위 80~200dp, 기본 120dp. dp는 화면 밀도를 고려한 크기입니다.
- 시작하면 설정 Activity만 닫히며 foreground service가 캐릭터를 표시합니다. 시스템의 프로세스를 강제 종료하는 방식이 아닙니다.
- 화면이 꺼지거나 잠겨 있으면 캐릭터를 숨기고 애니메이션을 멈춥니다. 잠금 해제 후 다시 표시합니다.
- 앱이 강제 종료되거나 재부팅되면 자동 재시작하지 않습니다.
- 알림 허용은 Android 13 이상에서 요청하며, 알림을 거절해도 표시 권한이 있으면 캐릭터를 시작합니다.
- Android 또는 대상 앱이 오버레이를 제한하는 보안 화면에서는 캐릭터가 보이지 않을 수 있습니다. 제조사 절전 기능으로 중단되면 배터리 설정에서 이 앱의 백그라운드 실행 허용을 확인하세요.
- Android 9~10의 가로 화면에서는 시스템 탐색 바/노치 근처의 여백이 정확하지 않을 수 있습니다. 위치는 직접 옮길 수 있습니다.
- 인터넷 권한, 광고, 분석 SDK, 부팅 자동 실행은 없습니다.

검증 범위
기존 버전의 기본 기능은 Android 11/12 에뮬레이터에서 검증했습니다. 이번 버전의 검증은 별도 verification.txt에 기록합니다.
Android 11(API30)과 Android 12(API31)의 드래그 재생 검증 결과는 verification.txt에 기록했습니다. 실제 휴대폰과 Android 9~10 및 13 이상에서의 실행은 별도 확인이 필요합니다. 지원 선언과 실기기 검증은 다릅니다.
구체적인 최종 결과는 verification.txt를 참고하세요.

소스 빌드
- Android Studio로 압축 해제한 usagi-source 폴더를 엽니다.
- Android SDK 36.1, 호환 JDK 및 Gradle Wrapper(9.4.1), Android Gradle Plugin 9.2.1을 사용합니다.
- local.properties에 sdk.dir=<본인 SDK 경로>를 설정하거나 ANDROID_HOME을 지정합니다.
- 개발용: ./gradlew testDebugUnitTest assembleDebug
- 정적 점검: ./gradlew lintRelease
- 서명 릴리스: 별도 usagi-signing-backup.zip의 usagi-release.jks와 signing.properties를 프로젝트 루트에 복사한 후 ./gradlew assembleRelease
- APK: app/build/outputs/apk/release/app-release.apk
- 서명 파일 없이 release를 빌드하면 서명되지 않은 APK가 생성됩니다.
- tests/의 ADB 스모크 테스트는 전용 에뮬레이터에서만 실행하세요. lifecycle_smoke.py의 UI 좌표는 API31/1080x2400/420dpi 구성 기준입니다.

서명키 보관
usagi-signing-backup.zip에는 이 앱 전용 개인 서명키와 비밀번호가 포함됩니다.
APK 설치만 할 때는 필요 없습니다. 향후 같은 앱으로 업데이트하려면 이 키가 필요하므로 개인 보관하고 공개 저장소에 올리지 마세요.
